Fill Missing Product Images

Finds every color variant missing a front or back image and fetches the correct flat/ghost product image from S&S Activewear.

Clean flat product shots — no models
Front and back images for every color variant
Only fills gaps — existing images are not overwritten

May take a few minutes. Do not close this tab.

Sync Bella+Canvas from SanMar

Syncs the Bella+Canvas catalog directly from SanMar — includes pricing, material info, and color variants.

Adds new styles and updates existing ones
Pulls real pricing and fabric/material details
Syncs color variants with front/back images

Requires SANMAR_CUSTOMER_NUMBER, SANMAR_USERNAME, and SANMAR_PASSWORD to be set in Railway.

Sync ALL Bella+Canvas

Syncs the complete Bella+Canvas catalog (160+ styles) from S&S Activewear.

Adds any new styles not yet in your store
Updates colors, sizes, and live inventory
Typically takes 3–5 minutes to complete

The page will load while the sync runs — do not close the tab.

Sync Mockup Styles

Syncs only styles that have mockup folders in uploads/mockups/ from S&S Activewear.

Discovers style folders from your mockups (e.g. 3001, 3001CVC)
Fetches colors, sizes, and live inventory from S&S
Links your mockup images to each color variant

Tip: Use Link Mockup Images to add styles and link images without needing the S&S API.

Test SanMar Connection

Sends a single test request to SanMar (style 3001C) to verify your credentials before running a full sync.

Credentials needed in Railway → Variables:
SANMAR_CUSTOMER_NUMBER  ·  SANMAR_USERNAME  ·  SANMAR_PASSWORD

Unlink S&S from Bella+Canvas

Removes the S&S Activewear API binding from all Bella+Canvas products so they can be managed by SanMar going forward.

Clears the S&S SKU reference from every color variant
Removes the S&S API data blob from each product
Prices, images, sizes, and colors are untouched

After this, use Sync Bella+Canvas from SanMar — your current prices will be preserved automatically on every future sync.
